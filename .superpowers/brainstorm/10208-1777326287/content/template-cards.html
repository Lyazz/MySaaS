Template Card Design

The templates grid has 12 themes. How should each card present itself?

A

Screenshot Preview

Tall card (portrait ratio) showing a real scaled-down screenshot of the storefront. Feels like picking a theme on Shopify. Most visual impact, but needs actual preview images per template.

B

Styled Swatch Card (keep current concept, elevate execution)

Keep the current mini mock-product preview with the template's own colors/fonts/radius. Improve the card layout, make the font/color pills cleaner, add a proper "Preview" button. No extra assets needed.

C

Horizontal List Row

Each template is a wide horizontal row: swatch on the left (small color block + font sample), name + description in the middle, action buttons on the right. Better for scanning, less visual but very scannable.
