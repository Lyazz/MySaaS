# Requirements

## Functional
- Multi-tenant stores with full data separation
- Subdomain + custom domain mapping
- Product catalog with variants
- COD checkout without account
- Orders dashboard per tenant
- Multi-language storefront (AR/FR/EN)
- SEO: SSR/hybrid, meta tags, sitemap per tenant
- Super-admin dashboard with tenant lifecycle controls and impersonation

## Non-functional
- Handle 100 tenants at launch
- Fast page load on mobile
- Secure tenant data isolation
- Observability: logs/errors (basic)
