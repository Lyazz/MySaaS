# Glossary

- Tenant: a society/business using the SaaS (one tenant = one store)
- End customer: shopper browsing tenant store and ordering via COD
- Tenant Admin: society user managing products/orders/settings
- Super-admin: platform owner (you)
- COD: Cash on Delivery
- Chargily: local payment gateway (planned)
- Host: domain/subdomain used to resolve tenant
