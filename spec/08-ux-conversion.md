# UX & Conversion (Algeria)

## Mobile-first principles
- Checkout must be short, clear, and fast
- Sticky CTA on product pages (“Commander الآن / Commander”)
- Minimal form fields (name, phone, wilaya; address optional or step 2)

## COD conversion recommendations (MVP-friendly)
- One-page checkout
- Phone number validation (format)
- WhatsApp button (optional MVP)
- Trust indicators:
  - COD badge
  - delivery badge
  - return policy snippet

## Localization
- Default language per tenant (AR/FR)
- Proper RTL support for Arabic
